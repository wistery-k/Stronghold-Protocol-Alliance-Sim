# 堅守協定シミュレーター

アークナイツの期間限定イベント「堅守協定：盟約（後期）」を、ブラウザでいつでも遊べるようにしたシミュレーターです。
オートチェス風のビルド（招集・精鋭化・盟約・堅守特性）と、ボス戦を見据えた DPS チェックができます。

オペレーター名・能力値・職分・スキル・盟約・堅守特性は本家のゲームデータに合わせています。
画像・音声などのアセットは含みません。本家の仕様が分からない部分（ショップの等級出現率、敵の能力など）は、妥当そうな挙動を独自に定めています。

## 遊び方

公開ページ： https://wistery-k.github.io/Stronghold-Protocol-Alliance-Sim/ （main への push で自動デプロイ）

ローカルで動かす場合：

```bash
npm install
npm run dev      # 開発サーバー起動
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
npm run balance  # 簡易ボットで多数回プレイしてバランスを確認
```

### ルール（現在の実装）

- **資金**：ラウンド n の開始時に n+3。特性による追加資金は次の準備フェーズで得る
- **招集**：等級Iは2、等級II〜IVは3、等級V〜VIは4。売却は1。更新は1
- **管理レベル**：1〜6。ショップ枠は 3/4/4/5/5/5。上げる価格は 5/8/11/12/13 から始まり、ラウンドごとに1ずつ下がる
- **配置**：盤面8枠、控え10枠
- **精鋭化**：同じオペレーターが3体（一部は2体）揃うと精鋭化。本家と同じく昇進2・高レベル・スキルLv7・モジュール付きの能力になる。精鋭化すると「管理レベル+1」の等級から3名が提示され、1名を無料で獲得できる
- **配置エリア**：4x4 のグリッド。各オペレーターは上下左右のいずれかを向く（カードの辺をクリックで変更）。「前方1マス」「後方1マス」は向きから見た相対位置、「左右一直線上」は絶対方角の横一列。【器用】の周囲効果、【エーギル】の捕食も位置どおりに働く
- **控え**：特性による獲得で上限を超えても破棄されない。超えている間は戦闘を開始できない
- **特別招集**：パインコーンを売却すると、等級I（精鋭なら等級V）から3名が提示され1名を無料で獲得
- **操作**：ドラッグ&ドロップで配置・入れ替え（招集欄へドロップで売却）、ダブルクリックで配置/控えへ移動、マウスオーバーで詳細表示
- **盟約**：核心盟約8種・追加盟約14種。異なるオペレーターの人数で発動し、加算数（層数）で効果が伸びる
- **堅守特性**：オペレーターごとの特性（獲得時・準備フェーズ開始/終了時・売却時・戦闘中など）。加算数を増やす特性が中心
- **装備**：ショップに装備枠が1つ（等級は管理レベルの出現率）。保管庫は6枠で、同じ装備2つで強化。オペレーターへドラッグで装備（1人2つまで・外せない、売却すると保管庫に戻る）。装備時に消滅する消耗型（資金・加算数・オペレーター獲得など）にも対応
- **盟約BAN**：ゲーム開始時に核心盟約からランダムに3つがBANされ、発動しなくなる。BANされた盟約を2つ以上持つオペレーターは出現しない
- **戦闘**：現状は「制限時間内に単体の標的を削り切れるか」の DPS チェック。ラウンド14・15がボス戦

準備画面の右側に、現在の編成で次の敵を倒せるかの予測（準備フェーズ終了時に増える加算数も反映）が常に表示されます。

### DPSサンドボックス

任意のオペレーター・精鋭化の有無・配置位置・加算数で、任意の敵に対するDPSを試せます。

## データ

`src/core/data/gamedata.json` は `scripts/extract_gamedata.py` で本家のゲームデータから生成しています。

- 大陸版データ（盟約（後期）のテーブル・能力値・スキル）: [Kengxxiao/ArknightsGameData](https://github.com/Kengxxiao/ArknightsGameData)
- 日本版データ（オペレーター名・スキル名の日本語表記）: [Kengxxiao/ArknightsGameData_YoStar](https://github.com/Kengxxiao/ArknightsGameData_YoStar)

```bash
python3 scripts/extract_gamedata.py <ArknightsGameData のパス> <ArknightsGameData_YoStar のパス>
```

日本版にまだ無いオペレーター名・スキルの日本語表記と、堅守特性の日本語訳はスクリプト内に持っています。

## シミュレーションの近似

DPS チェックは単体の敵に対する近似です。主な扱いは次のとおりです。

- 物理：`max(攻撃力 - 防御 × (1 - 防御無視率), 攻撃力 × 5%)`、術：`max(攻撃力 × (1 - 術耐性/100), 攻撃力 × 5%)`
- 攻撃間隔：`(基礎間隔 + スキルの間隔変化) × 100 / 攻撃速度`
- スキルは blackboard の攻撃力・攻撃速度・攻撃間隔・倍率・連撃数・弾薬数を読み取って再現（範囲攻撃・状態異常・召喚などは未再現）
- 被ダメージで SP が貯まるスキルは DPS チェックでは発動しない。医療・吟遊者は攻撃しない
- 確率効果（俊敏の SP 回復、シラクーザの確定ダメージなど）は期待値
- 装備の防御系・状態異常系の効果、敵の種類（海の怪物・ドローン）、凍結・睡眠・被撃破などの戦闘中イベントに関わる効果は未実装。画面上では「未再現」と表示

## 構成

```
src/
  core/                 UI に依存しない純粋なゲームロジック
    data/gamedata.json  本家から抽出したデータ
    data/units.ts       オペレーター
    data/alliances.ts   盟約の名称・発動人数・効果説明
    data/enemies.ts     DPS チェックの敵
    alliance.ts         盟約の発動判定と戦闘中の補正
    garrison.ts         準備フェーズ側の堅守特性
    sim.ts              DPS チェックの時間刻みシミュレーション
    game.ts             ゲーム状態とアクション（reducer 風）
    rules.ts            経済などの定数
  ui/                   素の DOM による画面
scripts/
  extract_gamedata.py   本家データの抽出
  autoplay.ts           バランス確認用ボット
tests/                  Vitest
```
