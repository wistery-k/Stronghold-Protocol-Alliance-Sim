# 堅守協定シミュレーター

アークナイツの期間限定イベント「堅守協定：盟約（後期）」を、ブラウザでいつでも遊べるようにしたシミュレーターです。
オートチェス風のビルド（招集・精鋭化・盟約・堅守特性）と、タワーディフェンス形式のオート戦闘で遊べます。

オペレーター名・能力値・職分・スキル・盟約・堅守特性は本家のゲームデータに合わせています。
画像・音声などのアセットは含みません。本家の仕様が分からない部分（ショップの等級出現率、戦闘の細部など）は、妥当そうな挙動を独自に定めています。

## 遊び方

公開ページ： https://wistery-k.github.io/Stronghold-Protocol-Alliance-Sim/ （main への push で自動デプロイ）

ローカルで動かす場合：

```bash
npm install
npm run dev      # 開発サーバー起動
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
npm run balance  # 簡易ボットで多数回プレイしてバランスを確認
```

### ルール（現在の実装）

- **戦術**：ゲーム開始時に40種から1つを選ぶ（ワルファリン・アーミヤ・ゴリアテ・ドゥ・ヤオイェなど）。戦術ごとに初期耐久値（20〜45）と独自の効果を持つ。効果の多く（盟約の加算数・資金・オペレーターや装備の獲得・戦闘中の補正）を再現。特殊法術や専用オペレーター、マップの変更が必要なもの（ドーベルマン・Pith・ダック卿・Touch）は耐久値のみで、一部だけのもの（オーキッド・キャサリン・シー・ナラントゥヤ）は選択画面に注記
- **懸賞**：3ラウンドの開始時に懸賞が3つ（I〜IIIの各段階から1つ、このゲームで選ばれた敵グループの種類を優先）提示され、1つを選ぶ。選んだ敵は3・4ラウンドに下の出現地点から追加で出現し、倒すと資金（1〜3）を次のラウンドに得る。候補は本家の「懸賞・飛行／頻度／損傷／持続／ステルス／折射 I〜III」
- **資金**：ラウンド n の開始時に n+3。使い切れなかった資金は戦闘開始時に失われる（繰り越さない）。特性による追加資金は次の準備フェーズで得る
- **招集**：等級Iは2、等級II〜IVは3、等級V〜VIは4。売却は1。更新は1
- **管理レベル**：1〜6。ショップ枠は 3/4/4/5/5/5。上げる価格は 5/8/11/12/13 から始まり、ラウンドごとに1ずつ下がる
- **配置**：盤面8枠、控え10枠
- **精鋭化**：同じオペレーターが3体（一部は2体）揃うと精鋭化。本家と同じく昇進2・高レベル・スキルLv7・モジュール付きの能力になる。精鋭化すると「管理レベル+1」の等級から3名が提示され、1名を無料で獲得できる
- **配置エリア**：下記のマップ。各オペレーターは上下左右のいずれかを向く（カードの辺をクリックで変更）。マウスを乗せると攻撃範囲を表示。「前方1マス」「後方1マス」は向きから見た相対位置、「左右一直線上」は絶対方角の横一列。【器用】の周囲効果、【エーギル】の捕食も位置どおりに働く
- **控え**：特性による獲得で上限を超えても破棄されない。超えている間は戦闘を開始できない
- **特別招集**：パインコーンを売却すると、等級I（精鋭なら等級V）から3名が提示され1名を無料で獲得
- **戦闘前に戻す**：戦闘結果の画面から、戦闘前の状態（盟約の加算数・資金・耐久値・乱数を含む）に戻せる。取り消した戦闘の結果とリプレイは準備画面で見返せる（リプレイはページを再読み込みするまで）。次のラウンドへ進むと戻せない
- **プロデュース戦略**：所持している間は装備枠に出ない（複数持つと資金が無限に増えるため）
- **ログ**：特性の発動・資金の増減・精鋭化・戦闘結果など、操作の直接の結果ではない出来事をラウンドごとに表示
- **操作**：ドラッグ&ドロップで配置・入れ替え（招集欄へドロップで売却）、ダブルクリックで配置/控えへ移動、マウスオーバーで詳細表示
- **盟約**：核心盟約8種・追加盟約14種。異なるオペレーターの人数で発動し、加算数（層数）で効果が伸びる（加算数の上限は999）。【孤高】と【秘技】は加算数を持たない。ほかに【秘技】（盤面の精鋭オペレーター2名で精鋭の攻撃力+30%、5名でさらに精鋭のSP消費-30%。所属に関係なく精鋭なら数に入り、加算数は持たない・BANされない）。ラウンド14・15は、戦闘中（配置時を含む）に堅守特性で得る加算数が無効（準備フェーズ開始時・終了時や獲得時の特性は働く）
- **堅守特性**：オペレーターごとの特性（獲得時・準備フェーズ開始/終了時・売却時・戦闘中など）。加算数を増やす特性が中心
- **装備**：ショップに装備枠が1つ（等級は管理レベルの出現率）。装備はオペレーターと同じ控えに置かれ、同じ装備2つで精鋭化。オペレーターへドラッグで装備（1人2つまで・外せない、売却すると控えに戻る）。装備時に消滅する消耗型（資金・加算数・オペレーター獲得など）にも対応。ダメージ種別の指定がない「ダメージをX軽減」（海溝の実験体）は物理・術・確定ダメージのすべてに効き、1回ごとのダメージから差し引く（0未満にはならない）。毎秒ダメージ（活性源石のマス・汚染秽蝕・スタン中の継続ダメージなど）は1秒ごとに1回受けるものとして毎秒の値から差し引く
- **盟約BAN**：ゲーム開始時に核心盟約3つ・追加盟約4つがランダムにBANされる。BANされた盟約を2つ以上持つオペレーターと、盟約を1つしか持たずその盟約がBANされているオペレーターは出現しない（BANされた盟約自体は揃えば発動する）
- **凍結**：凍結中も、次の準備フェーズ開始時に購入済みの枠は補充される
- **戦闘**：下記のオート戦闘。戦闘後はリプレイを再生できる

準備画面の右側に、現在の編成で次のラウンドの予測（準備フェーズ終了時に増える加算数も反映）が常に表示されます。

### オート戦闘（タワーディフェンス）

マップ（9列×4行）は本家の盟約（後期）の配置エリア8種（act1autochess_m01〜m04・act2autochess_m01〜m04。険境では同じ重みで抽選）から、ゲーム開始時に1つ抽選されます（戦術の選択画面・画面上部に表示。サンドボックスでは選択可能）。マップ1は低難易度でしか出ないため抽選から外している（サンドボックスでは選べる）。

1：地上（誰でも配置可・敵が通る）　2：敵の出現（右端の上下）　3：地上（誰でも配置可・敵は通らない）　4：配置不可　5：高台（遠距離のみ）　6：防衛マス　7：地上（配置不可・敵が通る。斜線で表示）　B：障害物（本家で配置エリアに置かれている木箱。配置不可・敵も通れない）

配置エリアは本家マップの1人用の区画（左上）で、木箱（trap_1105_accrate）と射撃台（trap_1106_achplat、高台として扱う）の位置も本家のデータどおり。マップ2の木箱（非表示のもの）は究極・死地では取り除かれているため置いていない。出現地点の間の2マスはボス戦以外と同じく塞いでいる（ボス戦でも開けていない）。

特殊なマス（地上として配置でき、敵も通る）。数値はデータに無いものは仮の値：

- 活性源石：配置した味方と通る敵は攻撃力+20%・攻撃速度+20、毎秒HP-70（本家の値）
- 沼地：配置した味方は攻撃速度-30、通る敵は移動速度×0.6・攻撃速度×0.7
- 換気口：配置した味方は敵の遠距離攻撃の対象にならない
- 深水区：通る敵は移動速度×0.6・攻撃速度×0.7、毎秒HP-100

- 敵は出現マスから防衛マスへ最短経路で進む。到達されると耐久値が減る（1ラウンドの減少は最大10）
- 地上マスのオペレーターはブロック数まで敵を止める。飛行の敵はブロックできず、近距離オペレーターは攻撃できない
- **敵の攻撃**：近接の敵はブロックしている相手を攻撃する。遠距離の敵は、ブロックされていれば相手を、そうでなければ射程内で最後に配置されたオペレーター（警報器を持つ者を優先）を攻撃する。戦闘開始時の配置順は絶対方角で左の列から、同じ列は上から（右・下ほど狙われやすい）。倒れたオペレーターは戦闘から外れ、ブロックしていた敵は再び進む
- **医療**：射程内でHP割合が最も低い味方を回復。群愈師は3人、鎖癒師は3人に跳ねて25%ずつ減少、療養師は遠い相手に80%、吟遊者は範囲内の全員を毎秒攻撃力の10%
- **コストと再配置**：戦闘開始時の配置はコスト不要。コストは10から毎秒1増える（上限99）。倒れたオペレーターは再配置時間（本家の値。助力・装備・特性の短縮も反映）が過ぎ、コストが足りていれば自動で同じ位置に再配置される。再配置のコストは初回が配置コストの1.5倍、2回目以降は2倍。再配置したオペレーターは「最後に配置された」扱いになる。先鋒などのスキルのコスト獲得（発動時・スキル中・攻撃ごと）と突撃兵の撃破時コスト+1にも対応
- **行商人**：配置中は3秒ごとにコストを3消費し、足りなければ撤退（再配置時間は短い）。琳琅スワイヤーは素質で、コスト消費のたびにコインと攻撃力+4%（最大8〜9層）を得て、コインで「シャンパン爆弾」（攻撃力155〜170%の物理ダメージ）を出す。致命傷を受けるとコスト5（使うたびに倍）を払ってHP70〜80%で耐える
- **元素損傷**：元素の敵（造波術師など11種）は攻撃時に攻撃力×比率の元素損傷を与え、1000で爆発する。神経（確定1000・10秒スタン）、侵蝕（防御-100を永続・物理800）、灼熱（術1200・10秒間術耐性-20）、壊死（15秒間スキル不可・SP毎秒-1・毎秒術100）。味方の元素損傷を与える側（ヴィルトゥオーサ・ニンフ・異格ブレイズ・ユー・フィラエ・ハロルド・純燼エイヤフィヤトラ）も再現し、敵は1000（ボス2000）で爆発（神経6000・侵蝕5000と防御-120・灼熱7000と術耐性-20・壊死は攻撃力低下と継続ダメージ）。爆発中は同じ元素が溜まらず、蓄積は爆発の終わりにかけて0へ戻る。ワンダーメディック系の治療は元素損傷も回復する。数値は [BWIKI の用語解説](https://wiki.biligame.com/arknights/%E6%9C%AF%E8%AF%AD%E9%87%8A%E4%B9%89) を参考にした
- **狩人**：スノーハンターは弾8発を持ち、攻撃のたびに1発消費して攻撃力120%。弾がないと攻撃できず、1秒攻撃しないと1秒に1発装填する。スキルは特殊弾の2連撃（ブロック中・凍結中の敵には倍率上昇）と素質の一撃・寒冷
- **旋輪射手**：ケイパーは旋回投擲物が手元にある時だけ攻撃できる。投擲物は射出時15マス/秒・回収時3.75マス/秒で往復し、戻るまで次の攻撃はできない。実効の間隔は「攻撃間隔1.0秒」と「0.5秒＋往復時間」の長い方で、1マス先1.0秒・2マス先約1.17秒・3マス先1.5秒（0.5秒は実機の計測に合わせた値）。スキル中は1回の攻撃で投擲物を2個放つ
- **呪癒師**：ヴァンデラ・ティティ・焔影リードは攻撃時、与ダメージの50%で味方1人を回復（対象は他の医療の治療と同じく、攻撃範囲内で回復を受け付ける味方のうちHP割合が最も低い味方）
- **浮遊ユニット（ロックロック・ミニマリスト・イェラ・荒蕪ラップランド）**：浮遊ユニットが攻撃対象に術ダメージを与え、同じ敵を連続で攻撃するたびに倍率が上がる（攻撃力の20%から1回ごとに+15%、上限110%。ロックロックのスキル中は上限170%）。イェラのスキル中は数+1。荒蕪ラップランドの素質「群狼の統率者」で、配置から20秒ごとに上限+10%→命中時に特殊能力を2秒無効化→数+1。S3「ディザストロ・フィナーレ」では浮遊ユニット（数+2）がザーロになって戦場全体の近い敵を追い（他のザーロが追っていない敵を優先、2マス/秒は仮）、取り付くと2秒の恐怖、周囲0.9マスの敵は移動速度-40%・1秒ごとに攻撃力100%の術ダメージ（重複なし）。スキル中は通常攻撃しない。リプレイではザーロをピンクの狼の頭、減速範囲を点線の円、ダメージを広がる輪で表示
- **寒冷・凍結**：寒冷は敵の攻撃速度-30。寒冷中に再び寒冷を受けると凍結（時間は残っていた寒冷と新しい寒冷の長い方）（移動・攻撃不可、術耐性-15）。寒冷はスキル（ノーシス・凛御シルバーアッシュ・イェラ・サンタラ）、イェラグの不融氷、【イェラグ】Lv2の寒風で付与。【イェラグ】の与ダメージは寒冷・凍結した敵に上昇。凍結で加算数を得る特性（シルバーアッシュ・プラマニクス・凛御シルバーアッシュの付与）、イェラガンドの涙の継続ダメージにも対応
- **睡眠**：ティティのスキル中の攻撃（2体同時）で敵を5秒睡眠（移動・攻撃不可、ティティ以外は攻撃の対象にできない）。スキル中に目覚めた・睡眠中に倒された敵は睡眠時間に応じた術ダメージ（攻撃力100%〜370/400%）を受け、周囲1.5マスの別の敵1体が睡眠。範囲内の味方が致命傷を受けるとHP1で睡眠（被弾しない。HP全回復かスキル終了で目覚める）。素質の睡眠中の敵への継続ダメージ・移動していない敵への追加ダメージ、範囲内の睡眠・スタン（神経損傷の爆発）で【サルゴン】【精密】を加算する堅守特性にも対応
- **連鎖術師**：最初の対象から近くの敵（1.5マス以内）へ跳躍し、最大3体（昇進2で4体）。跳躍ごとに15%減衰（レイズのスキル中は減衰なし）
- **シヴィライト・エテルナ**：S3で特性の回復が攻撃力の75%/秒になり（「微塵」で自身以外は1.5倍）、範囲内の味方に最大HP80%の鼓舞（攻撃力加算）、2秒ごとに範囲内の味方のHP割合をならす。堅守特性（前方1マスのオペレーターが戦闘中・配置時に特性で加算数を得るたびに+1/+2）は、相手の特性の上限（戦闘1回につき最大○）とは別に加算
- **素質**：オペレーターの素質（本家の通常の素質）を174件中131件（一部のみを含む）再現。自身・職業・周囲への能力上昇、確率の会心（期待値）、HPや時間・撃破に応じた上昇、脆弱・減速・ステルス無効、被弾時の無効化・回復、致命傷を耐える効果など。詳細画面に再現状況を表示し、一覧は [docs/talents.md](docs/talents.md)（`npx tsx scripts/talent_doc.ts` で生成）
- **武者・鎌**：他の味方から治療されない。武者（ウタゲ）は攻撃1回ごとにHP+70、鎌（ヒューマス・エンテレケイア・聖約イグゼキュター）は攻撃範囲内の敵全員を攻撃し、命中した敵1体ごとにHP+50（ブロック数まで）。ヒューマスのスキルの「勇猛」（HP50%以上で攻撃力+36%、80%以上で+72%）、聖約イグゼキュターのスキル中の近接攻撃の回避（期待値）と弾薬補充にも対応。エンテレケイアの「心燭」の召喚は未再現
- **配置時のスキル**：ウタゲ（HP50%減少、効果時間中は攻撃力上昇・術ダメージ）、グラベル（減っていくバリア）、血掟テキサスS3「ロヴェーショ」は配置時（ラウンド開始時・再配置時）に発動し、時間で終わる。血掟テキサスは配置時に周囲3×3の敵全員へ2連続の術ダメージと1.5秒スタン、その後スキル中（6/7秒）は1秒ごとに範囲内の敵最大2/3体へ剣雨（術ダメージと0.2秒スタン）。素質「テキサスの流儀」でスキル中に敵を倒すとHP全回復・スキル再発動（配置ごとに1回。配置時の攻撃も再び行う）。リプレイでは剣雨のたびに効果範囲が光り、命中した敵に剣と星（スタン）、スタン中の敵は黄色の点線の縁
- **近距離のブロック中の敵**：攻撃範囲の外でも、ブロックしている敵は攻撃できる
- **医療以外の治療**：グム（周囲の味方1人）、サリア（周囲の味方全員）、ブレミシャイン（スキル中の攻撃ごと）、ブリキ・引星ソーンズ（錬金ユニットの範囲で敵に継続術ダメージ・味方を継続回復）、スズラン（スキル中に範囲内を継続回復）、マドロック（自己回復）、スルト（全回復と継続的なHP減少）
- 耐久系の盟約（堅守・助力・エーギル・不屈・共同防衛・孤高）と装備（HP・防御力・術耐性・警報器・眠れる眷属・ペガサスの兜）も戦闘に反映
- 敵の攻撃力は本家の値（`ENEMY_ATK_SCALE` で調整可能）
- 攻撃範囲は本家の範囲データを向きに合わせて回転。ブロック中の敵、次に防衛マスに近い敵を優先して攻撃
- ラウンドごとの出現（数・時間・出現地点）は本家の険境（AC-2）のステージデータ。ステージの敵は「雑魚・エリート・強敵」の枠で、ラウンドの敵グループの敵に置き換わる
- **敵グループ**：主力部隊は常に出現し、特殊敵の6種（飛行・頻度・元素・持続・潜行・屈折）から3種がゲーム開始時に抽選される。ラウンドごとに主力部隊＋3種から1グループが選ばれ、その中の組み合わせ（強敵と、付随する雑魚・エリート）が重み付きで選ばれる。ステージの枠は地上用と飛行用の2組があり、飛行グループのラウンドは飛行用、それ以外は地上用の枠だけを使う。強敵は1ラウンド3体まで（本家の出現数がデータに無いための仮の上限。超えた枠はエリートになる）。前半（R1〜7）と後半で出る組み合わせが違う。出現する敵は本家の究極（AC-4）と同じく全種
- **狙う敵の順**：ブロックしている敵を最優先、次に挑発レベルの高い敵（本家データの値。剣・鎚・徹冑弾・ダブリンヘタイロイ衛兵など）、次に防衛地点までの経路が短い敵
- **敵の特殊能力**：ステルス（ブロックされている間しか狙えない）、攻撃回数で倒れる・ブロック不可（頻度の分裂体）、分裂（倒れると別の敵が出る）、復活（倒れると攻撃回数で倒せる状態になり、時間内に倒さないと復活）、屈折（術耐性+70）、盾（最初の1回の攻撃を無効）、防御低下（攻撃を受けるたびに防御・術耐性が下がる）、汚染（枯朽サルカズ戦士：倒れると半径2マスに8秒間の汚染秽蝕を残し、範囲内の味方は毎秒HPを失う。HP50%超で50、以下で25。防御・術耐性無視）、奇襲（山海衆精鋭・密使：ステルスが解けた後の最初の攻撃は攻撃力200%。再びステルスすると戻る）、臨戦（元核のマレフィセント：攻撃を受けると移動速度×4、1秒ごとに半径2.5マスの味方へ攻撃力10%の神経損傷。赘生甲壳の破壊は該当マップがないため未実装）、周囲攻撃（深溟のミキサー系：通常攻撃をせず、半径1.6マスの味方全員に毎秒術ダメージと神経損傷。換気口の上の味方は対象外）、抵抗（寒冷・凍結の時間-50%）、拘束と解放（囚人系：拘束中は攻撃速度-50。4回攻撃すると解放され攻撃力+50%。重罪拳闘士囚人は解放後に相手の防御力を80%無視、巨漢囚人は術耐性+40・毎秒HP150回復、凶悪犯は拘束中の防御力+300で、最初の解放時に場の敵をすべて解放）。
- **特殊能力無効化**：秘術法陣（攻撃した敵を5秒）、ラップランドの素質（通常1秒・精鋭5秒）、ポデンコのスキル（着弾地点の周囲を5秒）。無効化中の敵は屈折・ステルス・盾・復活・分裂を失う。元素損傷・持続ダメージ・敵のスキルなどの追加効果は未再現
- **味方のステルス**：【シラクーザ】Lv2の所属者は配置後の一定時間ステルスになり、敵の遠距離攻撃（ボスの通常攻撃を含む）の対象にならず、周囲攻撃・徹冑弾や手下の突進の爆発・臨戦の元素損傷も受けない（迷彩とは別の状態。ブロックしている近接の敵からは攻撃される）。リプレイではステルス中の敵・味方を半透明で表示
- **恐怖**：【シラクーザ】Lv2（攻撃時3%の確率で確定ダメージと3秒の恐怖。確率を攻撃ごとに貯めて1に達すると発生＝約33回に1回）。恐怖中の敵はブロックされず、攻撃せず、来た道を逃げる（ボスは対象外）。リプレイでは紫の縁。Lv2の確定ダメージは戦闘結果のダメージグラフで別の色（ピンク）に積み上げて表示
- ボス（ラウンド14：仮想敵：冑 HP60万・防御1000・術耐性25、ラウンド15：強化版の冑 HP120万＋「冑を斬る剣」「冑を砕く鎚」）は本家の耐久のまま。ステージ時間内に倒せないと残りHPに応じて耐久値が減る。冑は大型のボスで、移動せず右の2列×上の3行（(列,行)で(8,1)〜(9,3)）を占める。当たり判定はその左の列 (7,1)〜(7,3) も含み、そのどこかが攻撃範囲に入れば攻撃できる（(7,1)〜(7,3) は当たり判定のみで配置・敵の経路には影響せず、リプレイでは点線の枠）（範囲・連鎖攻撃でも1回だけ命中。対象を中心とする効果は(8,3)が中心）。通常攻撃はランダムな味方への術ダメージ、HP20%未満で受けるダメージ半減。剣と鎚（手下）は無敵でフィールド内を飛び回り、周囲1.6マスの味方に物理の範囲攻撃を続ける。防衛地点には入らず、ボスが倒れると消える。【破滅の災い】（初期SP5・必要SP25）：20秒後から25秒ごとに、攻撃力が最も高い味方へ<徹冑弾>を1発撃つ（ゲーム内の「HPが低下すると追加で発射」は誤りで増えない）。弾はHP8でどの攻撃も1ダメージの飛行敵で、挑発レベル+1。着弾すると目標と周囲8マスの味方に2.1秒のスタンと9.95秒間毎秒400の物理ダメージ（リプレイでは黄色の点線の範囲）。数値は攻略wikiの値。弾の速さ（1マス/秒）は仮。【死亡集群】：50秒ごと（ラウンド14は0秒、15は10秒から）に無人機（怪鳥。HPはボスの最大HP×2%と解釈）を1体召喚し、上の出現地点から防衛地点へ飛ぶ（召喚数は不明のため1体）。手下の突進：剣は25秒後・鎚は55秒後から80秒ごとに攻撃力が最も低い味方へ突っ込み、着弾で周囲8マスに10秒スタンと10秒間毎秒200の物理ダメージ、その後ボスのそばへ戻る。突進中は無敵が切れ、15回攻撃されると撃ち落とされて地上に落ち（近距離も攻撃でき、受けるダメージ1.3倍、受けたダメージの100%がボスにも入る）。突進の速さ（1マス/秒）は仮
- **リプレイの演出**：通常攻撃（遠距離は射線、近距離は斬撃。橙が物理・紫が術）、複数を巻き込む攻撃とスキル（真銀斬・ユー・異格ブレイズなどは攻撃範囲のマス、スプラッシュやニンフは着弾地点の円）、ブリキなどの設置範囲、治療（緑の線）、敵の遠距離攻撃（細い線）を表示。周囲攻撃の敵の範囲（紫の点線）、オペレーターの元素損傷（左上の丸。リングが爆発までの蓄積）、【サルゴン】の強化（左下の「AS+」）も表示し、戦闘結果には【サルゴン】の強化の最大・平均（ログにも記録）を出す
- 敵の HP は本家どおり（`src/core/rules.ts` の `ENEMY_HP_SCALE` で調整可能。以前は再現の足りない分を補うため0.5倍にしていた）
- 制限時間は本家のステージ時間か、最後の敵が経路を歩き切れる時間の長い方

### サンドボックス

任意のオペレーター・精鋭化の有無・配置位置・加算数で、任意のラウンドの戦闘を試してリプレイを見られます。

## データ

`src/core/data/gamedata.json` は `scripts/extract_gamedata.py` で本家のゲームデータから生成しています。

- 大陸版データ（盟約（後期）のテーブル・能力値・スキル）: [Kengxxiao/ArknightsGameData](https://github.com/Kengxxiao/ArknightsGameData)
- 日本版データ（オペレーター名・スキル名の日本語表記）: [Kengxxiao/ArknightsGameData_YoStar](https://github.com/Kengxxiao/ArknightsGameData_YoStar)

```bash
python3 scripts/extract_gamedata.py <ArknightsGameData のパス> <ArknightsGameData_YoStar のパス>
python3 scripts/extract_battle.py <ArknightsGameData のパス> <ArknightsGameData_YoStar のパス>
```

`src/core/data/battledata.json`（敵・ラウンドの出現・攻撃範囲）は `scripts/extract_battle.py` で生成しています。

日本版にまだ無いオペレーター名・スキルの日本語表記と、堅守特性の日本語訳はスクリプト内に持っています。

## シミュレーションの近似

主な扱いは次のとおりです。

- 物理：`max(攻撃力 - 防御 × (1 - 防御無視率), 攻撃力 × 5%)`、術：`max(攻撃力 × (1 - 術耐性/100), 攻撃力 × 5%)`
- 攻撃間隔：`(基礎間隔 + スキルの間隔変化) × 100 / 攻撃速度`
- スキルは blackboard の攻撃力・攻撃速度・攻撃間隔・倍率・連撃数・弾薬数・対象数・ブロック数を読み取って再現（状態異常・召喚などは未再現）。職分ごとの範囲攻撃・複数攻撃（術師の範囲、強襲者、鎖術師など）は簡易的に再現
- 被ダメージで SP が貯まるスキルは発動しない。医療・吟遊者は攻撃しない。攻撃系のスキルは範囲内に敵がいる時に発動
- 確率効果（俊敏の SP 回復、シラクーザの確定ダメージなど）は期待値（確率を累積し、1に達するたびに発生。積み立ては0.5から始めるので、発生回数は「試行回数×確率」の四捨五入になり、短い戦闘でも損得が偏らない）。俊敏で SP が回復した後は1秒間スキルを再発動しない（スキルの動作時間を再現していないため）
- 装備の防御系・状態異常系の効果、敵の種類（海の怪物・ドローン）、凍結・睡眠・被撃破などの戦闘中イベントに関わる効果は未実装。画面上では「未再現」と表示

```
    data/gamedata.json  本家から抽出したデータ

scripts/

tests/                  Vitest
```
