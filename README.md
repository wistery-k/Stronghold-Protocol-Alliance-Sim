# 堅守協定シミュレーター（非公式）

アークナイツの期間限定イベント「堅守協定」の**遊びの部分**を参考にした、非公式のファンメイド・シミュレーターです。
ブラウザで動くオートチェス風のビルドゲームと、ボス戦の DPS チェックができます。

> 本プロジェクトは Hypergryph / Yostar とは無関係です。ゲーム内の画像・音声・テキスト・キャラクター等の著作物は一切含みません。
> オペレーター名・陣営名・数値はすべてオリジナルの架空のものです。本家の仕様を厳密に再現することは目的とせず、妥当そうな挙動を独自に定めています。

## 遊び方

```bash
npm install
npm run dev      # 開発サーバー起動
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力
npm run balance  # 簡易ボットで多数回プレイしてバランスを確認
```

### プレイ

1. **招集**：資金を使ってショップからオペレーターを購入（価格 = 等級）。
2. **昇進**：同じオペレーターが同じ段階で3体揃うと自動で昇進（★1→★2→★3）。
3. **配置**：控えから配置へ。配置上限は「管理レベル + 2」。
4. **盟約**：配置中の異なるオペレーターの所属数で発動。核心盟約（陣営）と追加盟約（特性）の2系統。
   一部の盟約は戦闘のたびに**加算数**が貯まり、効果が伸びていく。
5. **戦闘**：現状は「制限時間内に標的を削り切れるか」の DPS チェック。失敗すると残りHPに応じて耐久値が減る。
   ラウンド5・10・15はボス戦。
6. 15ラウンド耐え切ればクリア。

準備画面の右側に、現在の編成で次の敵を倒せるかの**予測**が常に表示されます。

### DPSサンドボックス

任意のオペレーター・昇進段階・加算数で、任意の敵（ボス含む）に対するDPSを試せます。

## 構成

```
src/
  core/            UI に依存しない純粋なゲームロジック
    types.ts       型定義
    rules.ts       経済・確率・昇進などの定数
    data/          オペレーター・盟約・敵のデータ
    alliance.ts    盟約の発動判定と補正計算
    sim.ts         DPS チェックの時間刻みシミュレーション
    game.ts        ゲーム状態とアクション（reducer 風）
    rng.ts         シード付き乱数
  ui/              素の DOM による画面
  main.ts
tests/             Vitest
scripts/autoplay.ts  バランス確認用ボット
```

### ダメージ計算（暫定仕様）

- 物理：`max(攻撃力 - 防御 × (1 - 防御無視率), 攻撃力 × 5%)`
- 術：`max(攻撃力 × (1 - 術耐性/100), 攻撃力 × 5%)`（術耐性無視は固定値で減算）
- 確定：攻撃力そのまま
- 会心は期待値で計算（基礎会心倍率 1.5）。結果は決定的
- 攻撃間隔：`基礎間隔 × 100 / (100 + 攻撃速度)`
- スキル：自然回復（毎秒SP+1）または攻撃回復（攻撃ごとにSP+1）
